Chạy test thật trên code của bạn

Trong terminal của thư mục learning-hub, chạy:

npm run qa:serve -- --open

Link riêng xuất hiện trong terminal sẽ kết nối trang này với máy. Giữ terminal mở; cho phép truy cập mạng cục bộ nếu trình duyệt hỏi. Chrome mới có thể gọi quyền này là Loopback network.

Mở dashboard trên máy này ↗

Mã chỉ giữ trong phiên tab này. Link báo cáo công khai không chứa mã hoặc khóa API.

Claude Code trong VS Code

Nút sửa lỗi mở đúng workspace và gửi các assertion thất bại vào Claude Code. Cần cài extension Claude Code và đăng nhập Claude.

claude auth login

Hook Stop kiểm tra phiên bản code sau mỗi lượt Claude hoàn tất: sinh thêm test khi có thay đổi logic, chạy suite và cập nhật báo cáo Vercel.

Chưa có trạng thái sinh test.

Sinh test dùng tài khoản Claude của máy, giới hạn $2/lượt. Không ghi đè bộ test gốc. Thay đổi chỉ ở UI sẽ chạy suite hiện có và được ghi rõ là chưa sinh UI test.
